# Fidness - Segundo Avance

## Descripción
Fidness es una aplicación de escritorio desarrollada en Java que permite gestionar ejercicios y crear rutinas de entrenamiento personalizadas.

## Objetivo
Implementar las funcionalidades principales del sistema mediante programación orientada a objetos e interfaces gráficas.

## Tecnologías utilizadas
- Java
- Java Swing
- NetBeans
- GitHub

## Funcionalidades
- Inicio de sesión.
- Consulta de ejercicios.
- Gestión administrativa de ejercicios.
- Creación de rutinas personalizadas.
- Organización de ejercicios mediante series y repeticiones.
- Exportación de rutinas.

## Proyecto
Segundo avance del proyecto final del curso Programación Cliente/Servidor Concurrente.
